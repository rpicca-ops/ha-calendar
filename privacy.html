Privacy Policy

Last updated: November 2026

This policy applies to the private "Home Assistant – Personal Calendar Integration" described on the home page. It is operated by an individual for personal household use.

Google user data we access

With the explicit consent of the Google account owner, the application accesses Google Calendar data: the list of calendars and the events they contain (title, start and end time, location, description).

How the data is used

Calendar data is used only to display the owner's upcoming appointments on a private home dashboard and to power the owner's own home automations. It is not used for advertising, profiling, analytics or any other purpose.

Storage and sharing

  • Data is processed and temporarily cached on a Home Assistant server located in the owner's home. It is not copied to any external server operated by us.
  • We do not sell, share, transfer or disclose Google user data to any third party.
  • No human reads the data except the account owner and family members who already have access to that calendar.

Limited Use

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and deletion

Cached data is replaced at every refresh. The owner can revoke access at any time at myaccount.google.com/permissions and delete the integration from Home Assistant, which removes the stored authorization.
